# ADR-0002: ICT Intelligent Procurement Platform

- Status: Accepted
- Date: 2026-07-30

## Context

The external product is known as ICT Integration Hub. The architecture also needs a precise internal name for procurement decisioning, rule execution, traceability, and advisory AI.

## Decision

Use **ICT Integration Hub** as the external product name and **ICT Intelligent Procurement Platform (IPP)** as the internal architecture name.

ICT IPP represents AI-assisted procurement automation built on deterministic business rules.

## Consequences

Documentation, ADRs, and code comments may use ICT IPP when describing architecture. User-facing product references should continue to use ICT Integration Hub unless a product decision changes branding.
