# ADR-0007: Company Memory

- Status: Accepted
- Date: 2026-07-30

## Context

Procurement review benefits from company-specific history such as vendor aliases, prior decisions, and traceability patterns. That memory must not become hidden business authority.

## Decision

Company Memory may provide context to ICT IPP and AI Advisor. It does not override deterministic rules.

## Consequences

Future implementation must define retention, privacy, write approval, audit, and deletion rules. Any memory used in AI recommendations should be referenceable.
